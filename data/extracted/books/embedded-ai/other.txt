Hardware Requirements
       This section outlines the core development boards and sensors used across
       the projects in this book, highlighting why each was selected and what it
       contributes to the learning experience. We’ve prioritized accessible, well-
       supported platforms that are widely available, but we also include more spe-
       cialized boards where necessary to demonstrate real-world capabilities like
       computer vision, sound generation, or sensor fusion. Think of this as your
       starter kit for building intelligent devices at the edge.
            In addition to the embedded hardware, you’ll need a laptop or desktop
       computer capable of running Python scripts and training machine learning
       models. Any modern system, whether running Windows, macOS, or Linux,
       should be sufficient, as long as it supports Python 3.x and can handle basic
       ML training workloads.
            While this book focuses on embedded AI, the reality is that much of
       the model training, especially for deep learning, is performed on laptops,
       on desktops, or in the cloud. These environments offer the processing
       power and memory required to handle large datasets and complex com-
       putations that would be impractical on microcontrollers. Once trained,
       models are then quantized, compressed, and optimized for deployment on
       embedded hardware. This separation of concerns (train on the desktop,
       deploy at the edge) is a pragmatic and widely adopted workflow.
            Each project has a parts list so you can get exactly what you need when
       you need it. You do not have to buy everything in advance, and you do not
       need most of the boards to get started.
            A good portion of the book needs no hardware at all. Around a quar-
       ter of the chapters can be followed entirely on a laptop, using tools like
       TensorFlow and scikit-learn. Beyond that, two-thirds of the chapters can be
       completed with just two boards: the Arduino UNO and the Raspberry Pi
       Pico. Together, these cost around $35, and the Pico on its own is under $5.
       Add the Nano 33 BLE Sense, and you can build close to three-quarters of
       the projects in the book for a combined cost of around $70.
            These three boards (the UNO, the Pico, and the Nano 33 BLE Sense)
       are reused across many projects, so they are the ones worth investing in up
       front. The remaining boards are each used in a single chapter, so you can
       buy them only if you decide to build those particular projects.
            If you want to plan ahead, the full set of boards and platforms used

Using Python on a Windows Arm PC
       If you’re running Windows on an Arm64 machine, note that Python’s
       native Arm64 builds do not yet support all required libraries. At the time
       of writing, pandas was not available for Python 3.11, 3.12, or 3.13 on native
       Windows Arm64, and Python 3.10 has no native Arm64 build at all.
            The workaround is to install the standard x86 version of Python,
       which runs under emulation on Arm64 hardware. While training will be
       slower than on a native x86 machine, all libraries will install and function
       correctly.


Tools for Assembly and Debugging
       In addition to electronic components and microcontrollers, you’ll need a
       few basic tools to build and troubleshoot the projects in this book. Nothing
       fancy—just the kind of gear you’d find in a typical maker’s toolbox. A good
       set of screwdrivers, long-nosed pliers, wire cutters, and jumper wires will
       go a long way. If you plan to assemble your own PCBs, a soldering iron and
       some soldering accessories will also be necessary.
